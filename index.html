Smart Room Control System

A smart room control system featuring automatic lighting and window control based on light intensity measured by Light sensor, climate conditioning through temperature-controlled fan operation measured by Temperature sensor, and ultrasonic security monitoring considering the movement around outside the room nearby the door. This system is controlled remotely via Adafruit IO website as dashboard for IoT integration, using Wireless communication and Internet protocol as set of rules to govern the communication.

Project Introduction

A comprehensive overview of our Smart Room Control System

1

What is the Smart Room Control System?

Our Smart Room Control System is an Internet of Things (IoT) solution that automates various room functions including lighting that will depend on the light intensity and window operation (OPENING & CLOSING) via Light Dependent Resistor (LDR) sensor, climate control throughout Digital humidity and temperature sensor (DHT11), and ultrasonic security monitoring that detects intruders that come closer to the door. The system uses sensors to monitor environmental conditions and automatically adjusts room settings for optimal comfort and energy efficiency.

2

Key Features

  • Automatic Lighting: Lights turn on/off based on ambient light levels or light intensity
  • Climate Control: Fan activates when temperature exceeds set thresholds
  • Window Automation: Windows open/close based on light intensity
  • Ultrasonic Security: Motion detection with buzzer and LED alerts when objects are 30cm or further
  • Remote Monitoring: Real-time control and monitoring via Adafruit IO dashboard
3

Technology Stack

The system is built using ESP32 microcontroller, various sensors (DHT11, LDR, Ultrasonic), actuators (relays, servo motors, fan and lamp), indicators (LEDs and buzzer), display system (LCD_I2C Screen) and communicates via MQTT protocol with Adafruit IO for remote access and control.

Working Principle & Technical Explanation

How our Smart Room Control System operates

1

Sensor Data Collection

The system continuously monitors environmental conditions using DHT11 (temperature/humidity) then after collecting data sends it to the microcontroller (ESP32). LDR (light sensor) measures the amount of light value then sends them to the ESP32, and HC-SR04 ultrasonic sensors (detecting the movement around the door) and send data to ESP32 too. The ESP32 as microcontroller of the system which serves as the central processing unit, receiving, processing, and sending commands to control the fan and lamp throughout light amount, switching on/off (Relay1 pin) Lamp and servo motor (as window controller) according to the brightness or darkness. It tells (Relay2 pin) fan to be on/off according to the temperature sensed inside the room. According to the ultrasonic sensor data collected it turns led white/led red on/off when any obstacle detected. After all we have monitoring system to show us needed information and help us for maintenance.

2

Automated Decision Making

Based on predefined thresholds, the system automatically controls devices:

  • Lights turn ON when LDR value < 2700, OFF when > 1500
  • Fan activates when temperature exceeds 28°C
  • Windows open when light level is sufficient and close when dark
  • Buzzer activates when objects are detected at 30cm or further
3

Ultrasonic Security System

The HC-SR04 ultrasonic sensor continuously measures distance. When objects are detected at 30cm or further, the system triggers a buzzer alarm and activates the red LED. White LED indicates safe distance (objects closer than 50cm).

4

MQTT Communication

The system connects to Adafruit IO via MQTT protocol to publish sensor data and receive control commands through the dashboard, enabling remote monitoring and control from anywhere.

5

Manual Override

All automated functions can be manually controlled remotely via MQTT commands to Adafruit IO.

Project Components

Hardware and software components used in our Smart Home Automation System

ESP32 Microcontroller

The brain of our system, handling all sensor data processing, system control, and WiFi communication through the dashboard.

DHT11 Sensor

Digital humidity and temperature sensor that measures environmental conditions for automatic climate control and fan operation.

LDR Light Sensor

Light Dependent Resistor that detects ambient light levels for automatic lighting control based on light intensity.

HC-SR04 Ultrasonic Sensor

Distance measurement sensor for security monitoring, triggers alerts when objects are detected at 30cm or further.

Relay Modules

Controls high-power devices like lights and fans safely with low-voltage signals from the ESP32.

Servo Motor

Controls window opening and closing based on light levels and automation rules with 180-degree movement.

12V DC Fan

Cooling fan controlled by relay module, automatically turns on when temperature exceeds 28°C for climate control.

Lamp

Lighting device controlled by relay module, automatically turns on/off based on ambient light levels detected by LDR sensor.

LED Indicators

Green and red LEDs used to indicate security status - green for safe distance, red for object detection.

Buzzer

Audio alert device that sounds for 2 seconds when objects are detected at 30cm or further for security alerts.

LCD_I2C Display

LCD screen used to display the situation inside and outside the room.
